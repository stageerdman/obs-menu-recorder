# INIT update — decisions & lessons

This was the original RecBar build (menu-bar OBS recorder). The project has since
grown well past this update through later work (idle resource minimization, the
silence/presence watchdog, Meetings/Audio/Guide restructure, Captain Log mode, the
Library window + OneDrive sharing).

The durable, hard-won knowledge from all of that — architecture, obs-websocket
quirks, the OBS quit-time crash investigation, the camera-stuck-open bug, watchdog
threshold tuning, and every "not yet verified" caveat — lives in the root
**`CLAUDE.md`** "Project knowledge" section, which is kept current. This file exists
only to satisfy the updates/ convention for the INIT update; it is not the place to
look for RecBar's accumulated lessons.

- `update v1.md` — the original INIT build spec (was `INIT.md` at the repo root).
- `handoff-notes.md` — the 2026-08-21 mid-build handoff snapshot (was `PROGRESS.md`).
  Historical; superseded by everything built since.
